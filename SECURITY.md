# Security policy

Please do not post credentials, access tokens, private source, or exploitable details in a public issue.

For a suspected vulnerability, use GitHub's private security advisory flow: [Report a vulnerability](https://github.com/mandarange/Sneakoscope-Codex/security/advisories/new). Include the affected version, reproduction steps, impact, and a safe contact path. The project will acknowledge reports when practical and will coordinate disclosure around a released fix.

If the private advisory flow is unavailable, open a minimal issue asking for a private contact path without including the vulnerability details.
