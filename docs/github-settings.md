# GitHub settings to apply after review

These settings require repository-owner action and are intentionally not applied by this local-only task.

- **About description:** `Local trust layer for Codex: bounded context, machine-verifiable evidence, and test-backed release gates.`
- **Topics:** `codex`, `codex-cli`, `chatgpt-desktop`, `ai-coding-agents`, `agent-orchestration`, `developer-tools`, `release-verification`, `proof-gates`, `typescript`, `macos`.
- **Website:** point to the maintained documentation or project page once its URL is confirmed; leave blank rather than using a placeholder.
- **Releases:** align the latest GitHub release/tag with the intended npm version before publishing or sharing the package.
- **Actions:** ensure the new `CI` workflow is enabled and its default-branch badge is green before sharing the repository.
- **Discussions:** enable only if the maintainer can answer them; pin the quick-start thread if enabled.
- **Security:** enable private vulnerability reporting if the account plan supports it and link `SECURITY.md` from the repository's Security tab.
